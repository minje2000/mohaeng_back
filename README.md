모행 Backend (모두의 모든 행사)
  
  - AI 기반 행사 검수 기능을 활용한 통합 이벤트 관리 플랫폼 백엔드
  누구나 행사를 등록하고 참여할 수 있는 플랫폼으로, AI 검수 기능을 통해 행사 등록을 보조하고 관리자 검수 프로세스를 제공하는 서비스입니다.

프로젝트 소개
  - 모행(MOHAENG)은 지역 기반 행사 정보를 공유하고 참여할 수 있는 플랫폼입니다.
  사용자는 행사를 등록하고 참여할 수 있으며, 리뷰 작성, 관심행사 등록, 문의, 신고 기능 등을 이용할 수 있습니다.
  행사 등록 시 AI가 행사 내용을 분석하여 위험도를 평가하고, 위험 점수에 따라 관리자 검수 프로세스를 진행하도록 설계하였습니다.

트러블 슈팅
  1. AI 검수 기능 추가 과정에서 발생한 상태 관리 문제
     
문제
  프로젝트 진행 중 AI 검수 기능을 추가하면서 행사 등록 상태와 검수 상태를 하나의 컬럼으로 관리하였습니다.
  이로 인해 행사 상태 변경 시 검수 상태가 함께 변경되거나 관리자 검수 목록 조회 시 예상치 못한 데이터 누락 문제가 발생하였습니다.
  
원인
  행사 상태와 검수 상태가 서로 다른 역할을 수행함에도 하나의 컬럼에 저장하여 상태 관리 책임이 분리되지 않았습니다.
  
해결
  검수 상태 컬럼을 별도로 추가하여 행사 상태와 독립적으로 관리하도록 수정하였습니다.
  
결과
  데이터 정합성 향상
  관리자 검수 기능 안정화
  유지보수성 개선
  
2. Git 협업 충돌 문제
  
문제
  프로젝트 초기에 Git 사용 경험이 부족하여 브랜치 충돌이 자주 발생하였습니다.
  
해결
  브랜치 전략 수립
  Merge 규칙 정의
  코드 리뷰 후 병합 진행
  
결과
  협업 효율 향상
  충돌 감소
  코드 관리 안정화

프로젝트 회고
AI 검수 기능은 프로젝트 초기에 존재하지 않았던 기능이었습니다.
  프로젝트 진행 중 기능을 추가하면서 데이터베이스 설계, 백엔드 로직, 프론트엔드 화면 및 관리자 기능까지 전반적인 수정이 필요했습니다.
  이를 통해 기능 구현뿐 아니라 서비스 구조와 데이터 흐름을 고려한 설계의 중요성을 경험할 수 있었습니다.
  또한 AI가 항상 올바른 결과를 반환하지 않을 수 있다는 점을 고려하여 관리자 검수와 신고 기능을 함께 설계하며 서비스 안정성을 높이고자 하였습니다.
